# Clover – Wellness & Habit Tracking App

Clover is a simple and intuitive wellness application designed to help users build healthy habits, plan meals, and stay mindful in their daily routines.

---

## Features

- **Meal Planning** – Plan daily meals and track eating habits  
- **Habit Tracking** – Create and monitor healthy daily habits  
- **Wellness Focus** – Encourages balance, mindfulness, and self-care  
- **Calming UI** – Floral-inspired colors with a soft, feminine aesthetic  
- **Authentication Screens** – Login, Register, and Forgot Password flows  

---

## Built With

- Flutter (Dart)
- Android Studio
